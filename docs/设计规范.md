# Shared Center — 前端设计规范

> 设计定位:**极简 NAS / 浅色系 / 大圆角矩形**
> 适用项目:家庭服务中枢(frontend/,Vue 3 + Naive UI + ECharts)
> 核心样式文件:[frontend/src/styles/global.css](frontend/src/styles/global.css)

---

## 1. 技术栈

| 层 | 选型 | 用途 |
|---|---|---|
| 框架 | Vue 3 (`<script setup>` + TS) | 页面与组件 |
| UI 组件库 | **Naive UI** | 表单、表格、弹窗、消息通知等 |
| 图表 | **ECharts** (自封装 `TrendChart.vue`) | 历史趋势、频率视图 |
| 图标 | Ionicons 5 (`@vicons/ionicons5`,`ion-icon` 标签) | 导航、卡片、按钮图标 |
| 状态管理 | 无 Pinia,Composables + ref | 全局状态 |

## 2. 色彩体系

| 变量 | 色值 | 用途 |
|---|---|---|
| `--bg-page` | `#F0F2F5` | 页面背景(浅灰蓝) |
| `--bg-card` | `#FFFFFF` | 卡片 / 表格 / 弹窗背景 |
| `--bg-sidebar` | `#F8F9FB` | 侧边栏背景 |
| `--bg-sidebar-hover` | `#EEF1F5` | 侧边栏菜单悬停 |
| `--bg-sidebar-active` | `#E8EDF4` | 侧边栏菜单选中 |
| `--text-primary` | `#1A1D26` | 主文字(标题、数值) |
| `--text-secondary` | `#8B95A5` | 次要文字(标签、说明、表头) |
| `--text-sidebar` | `#5F6B7A` | 侧边栏菜单文字 |
| `--text-sidebar-active` | `#2C3E68` | 侧边栏菜单选中文字 |
| `--border-light` | `#EDF0F4` | 卡片内部分割线 / 表格行分隔 |
| `--border-card` | `#E8ECF1` | 卡片边框 / 输入框边框 |

### 2.2 状态色(柔化,不做纯饱和色)

| 变量 | 色值 | 用途 |
|---|---|---|
| `--color-info`(主色) | `#5B8DEF` | 品牌蓝:按钮、链接、图表线、选中态、图标色 |
| `--color-success` | `#22C55E` | 在线、成功、新增值 |
| `--color-warning` | `#F59E0B` | 告警、磁盘占用 |
| `--color-danger` | `#EF4444` | 离线、失败、删除 |

**约定**:
- 图表折线固定用主色 `#5B8DEF`,2px 宽。
- 设备指标进度条按语义分色:CPU=蓝、MEM=绿、DSK=黄、VOL=紫 `#A855F7`(禁用时灰 `#9CA3AF`)。
- 图标底色用主色的 10% 透明版本,如 `rgba(91, 141, 239, 0.1)`。

## 3. 圆角体系(全面偏大,这是本风格最明显的特征)

| 变量 | 值 | 用途 |
|---|---|---|
| `--radius-xs` | 6px | 标签 Tag |
| `--radius-sm` | 10px | 按钮、输入框、菜单项、下拉框 |
| `--radius-md` | 14px | 小卡片、弹窗内卡片、Popover |
| `--radius-lg` | **18px** | 标准卡片、数据表格容器 |
| `--radius-xl` | **24px** | 登录卡片、Modal |
| `--radius-full` | 999px | 胶囊:开关、状态指示、进度条 |

> 卡片 `18px`、弹窗 `24px` 是辨识度最高的数值,其他项目沿用这组即可。

---

## 4. 阴影体系(柔和、低对比,靠"层次"而非"重影"区分)

| 变量 | 值 | 用途 |
|---|---|---|
| `--shadow-card` | `0 1px 2px rgba(0,0,0,0.04), 0 0 0 1px rgba(0,0,0,0.02)` | 卡片默认态(带 1px 轻描边) |
| `--shadow-card-hover` | `0 4px 16px rgba(0,0,0,0.06), 0 0 0 1px rgba(0,0,0,0.03)` | 卡片悬停(配合上浮) |
| `--shadow-modal` | `0 12px 40px rgba(0,0,0,0.08)` | 弹窗 / 登录卡片 |
| 移动端侧边栏 | `4px 0 24px rgba(0,0,0,0.12)` | 抽屉式侧边栏 |

## 5. 字体与字号

```css
--font-family: -apple-system, BlinkMacSystemFont, "Segoe UI",
               "PingFang SC", "Microsoft YaHei", sans-serif;
```

| 场景 | 字号 / 字重 | 备注 |
|---|---|---|
| 页面大标题 `.page-title` | 24px / 700,`letter-spacing: -0.3px` | 移动端降至 18px |
| 卡片标题 / 设备名 | 16px / 600 | |
| 大数值 `.stat-value` | **28px / 700**,`letter-spacing: -0.5px` | 仪表盘核心数字 |
| 正文 / 表体 | 14px / 400 | 全局 `font-size: 14px` |
| 辅助文字(标签、表头、时间) | 12px / 500~600 | 表头加粗 + 灰 |
| 迷你标签(指标名 CPU/MEM) | 10px / 600,`letter-spacing: 0.5px` | |
| 等宽 | `Consolas / Courier New / monospace` | 设备 hostname、TOTP 验证码 |

**约定**:
- 所有数字用 `font-variant-numeric: tabular-nums`(等宽数字,表列对齐)。
- 侧边栏分组标题:11px / 600,大写,`letter-spacing: 1px`。
- 全局 `-webkit-font-smoothing: antialiased`。

## 7. 布局结构

```
┌──────────────┬──────────────────────────────┐
│ 侧边栏 230px  │  顶栏 52px(毛玻璃)            │
│ (fixed)      ├──────────────────────────────┤
│  品牌 Logo    │  页面内容(滚动)               │
│  分组菜单     │  max-width: 1440px 居中       │
│  v1.0.0      │                              │
└──────────────┴──────────────────────────────┘
```

| 区域 | 尺寸 / 样式 |
|---|---|
| 侧边栏 | `width: 230px`、fixed 定位、背景 `#F8F9FB`、右侧 1px 边框 |
| 顶栏 | `height: 52px`、fixed、`background: rgba(255,255,255,0.85)` + `backdrop-filter: blur(12px)`(毛玻璃) |
| 内容区 | `margin-left: 230px` + `margin-top: 52px`,滚动,过渡 `0.25s ease` |
| 页面容器 | `.page-container`:padding 24px、`max-width: 1440px` 居中 |
| 卡片网格 | `auto-fill, minmax(250px, 1fr)`(统计卡)/ `minmax(280px, 1fr)`(设备卡),gap 16px |

**顶栏右侧信息流**:用户名 → 实时连接状态胶囊(圆点+文字,可点击切换)→ 实时时钟 → 退出按钮。

## 8. 组件风格规范(Naive UI + 覆盖)

| 组件 | 规范 |
|---|---|
| 卡片 `.n-card` | 圆角 `18px`、默认阴影+1px 边框、hover 阴影加深;内容 padding `20px 24px` |
| 按钮 `.n-button` | 圆角 `10px`、字重 500;主按钮背景 = 主色 `#5B8DEF`,hover 透明度 0.9;次按钮灰边框 |
| 输入框 / 下拉 / 文本域 | 圆角 `10px` |
| 数据表格 | 表头背景 `#F9FAFB`、12px 粗体灰字;行底边 1px 浅分隔线;容器套卡片样式 |
| 标签 `.n-tag` | 圆角 `6px`;设备卡内用 `size="tiny"`、无边框、`round` 胶囊 |
| 开关 | 轨道全圆角(胶囊) |
| 弹窗 Modal | 圆角 `24px`、`--shadow-modal` |
| Popover | 圆角 `14px` |
| 滚动条 | 5px 细滚动条,滑块 `#D1D6E0`,悬停 `#B0B8C4`,轨道透明 |

### 8.1 特色小部件

- **状态指示点 `.status-dot`**:9px 圆点,带 2px 浅色光晕(`box-shadow: 0 0 0 2px rgba(0,0,0,0.04)`);online=绿 / idle=灰 / warning=黄 / offline=红。顶栏 WebSocket 状态和仪表盘共用。
- **统计卡 StatCard**:46px 圆角方块图标(品牌色 10% 底 + 品牌色图标)→ 大数值 28px + `/总数` 次级 → 12px 灰色标签;可带趋势箭头(涨绿跌红)、整卡可点击跳转。
- **指标进度条**:5px 高胶囊轨道 + 填充,填充色按指标语义分色,宽度过渡 `0.5s ease`;整行可点击查看历史。
- **状态卡片 hover**:`translateY(-2px)` 上浮 + 阴影加深,`transition: all 0.2s ease`。
- **实时小圆点 `.live-dot`**:8px 绿点 + `live-pulse` 呼吸动画(1.6s 循环透明度 1→0.35)。
- **TOTP 验证码卡**:与 StatCard 完全同构对齐;验证码 28px 等宽粗体蓝色、`letter-spacing: 3px`,点击复制,带 30s 倒计时进度条(4px,`transition: width 1s linear`)。
- **HA 子设备摘要**:灰色胶囊 chips(emoji 图标 + 设备名)+ "共 N 个变量"。

## 9. 图表风格(TrendChart.vue,ECharts)

| 项 | 值 |
|---|---|
| 折线 | 2px、主色 `#5B8DEF`、`smooth: 0.15`(小曲率)、无散点 |
| 状态图 | 阶梯线 `step: 'end'`,y 轴固定 0/1,标签显示 开/关 |
| 标题 | 14px、`#1A1D26`、居中 |
| 布局 | `grid: { left: 70, right: 25, top: 42, bottom: 32 }` |
| 时间轴 | `type: 'time'`,默认显示最近 48h;`dataZoom: type 'inside'` 滚轮缩放/拖拽平移 |
| Tooltip | axis 触发,显示"时间 + 值" |
| 交互 | 单击图表携带当前可视窗口通知外部;拖到最早边界自动加载更早数据;窗口变化外部频率视图自适应粒度 |
| 容器 | 白卡 + 1px 边框 + 14px 圆角 + 卡片阴影,高 380px |

## 10. 动效约定

| 场景 | 参数 |
|---|---|
| 卡片 hover | `transition: all 0.2s ease` |
| 按钮 / 菜单 / 图标 hover | `0.15s ease` |
| 侧边栏 / 内容区伸缩 | `transform / margin 0.25s ease` |
| 进度条填充 | `width 0.5s ease`(TOTP 倒计时 `1s linear`) |
| 呼吸指示点 | 1.6s 循环透明度脉冲 |
| 页面切换 fade | 0.2s opacity |

---

## 11. 响应式规则

| 断点 | 行为 |
|---|---|
| ≤ 900px | 剪切板大卡片(2×2 网格)恢复单格 |
| ≤ 767px | 侧边栏变抽屉(移出屏幕 + 遮罩 `rgba(0,0,0,0.35)` + 投影);多列网格变单列;页面 padding 缩至 12px;大标题缩至 18px |

## 12. 图标与 Logo

- **Logo**:30×30 圆角矩形(SVG,`rx=9`,`#5B8DEF` 底 + 白色圆角方块组),登录页放大到 40px。
- **导航图标**:Ionicons outline 风格(如 `grid-outline`、`time-outline`),20px、默认透明度 0.7,选中时透明度 1 且染主色。
- **设备类型图标**:用 emoji(🖥️ server 📦 nas 💾 iot 🏠 docker 🐳 router 📡 等)。
- **HA 子设备属性图标**:emoji(🔘 开关 ⚡ 功率 🌡️ 温度 💧 湿度 📍 位置 💡 亮度 🔋 电量 等)。

## 13. 新页面开发速查(保持风格一致)

1. 页面结构:`<div class="page-container">` → `.page-header`(标题 + 操作区)→ 卡片网格/表格。
2. 标题用 `.page-title`(24px/700),表格容器直接给 `style="background:var(--bg-card);border-radius:var(--radius-lg);box-shadow:var(--shadow-card)"`。
3. 所有色值只引用 CSS 变量,禁止硬编码(主色 `#5B8DEF` 除外,组件 props 传图标色时可用)。
4. 数据表格表头样式、输入框圆角等由 global.css 的 Naive UI 覆盖自动生效,无需重复写。
5. 数字展示加 `tabular-nums`;状态用 `.status-dot`;可跳转卡片给 hover 上浮效果。
6. 移动端自查:网格单列、侧边栏抽屉、padding 12px。
