## 技术要点

- **Vue + structuredClone 陷阱**：ref 内对象是 reactive Proxy，克隆前必须 `toRaw`。
- **排序不变量**：数组顺序与 `order` 字段必须一致；拖拽先重编号再 `normalizeOrder`。
- **拖拽库懒加载**：vuedraggable 用 defineAsyncComponent 按需加载（编辑模式才下载），主包保持 ~59KB gzip。
- **测试隔离**：Pinia 测试用 `setActivePinia(createPinia())` + `localStorage.clear()`；store 测试直接赋值 `baseData` 绕过 fetch，不污染 `public/data/links.json`。
- **window.open 打桩**：`vi.stubGlobal('open', ...)` 断言搜索跳转行为。
- **matchMedia 模拟**：jsdom 不实现，settings 测试手动 stub。
